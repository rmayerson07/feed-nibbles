# Feed Nibbles

A learning game for 3-year-olds. Nibbles is hungry: feed him the right letter cookie (ABC), count out snacks (123), or match simple food words (Words).

- Plain HTML, no accounts, no ads, no tracking, no AI.
- Works offline after the first visit.
- Add it to a phone's home screen to use it like an app.

Grown-up settings (sliders button): uppercase/lowercase letters, count to 5 or 10, hide pictures on word cards, sound on/off and a sound test.
